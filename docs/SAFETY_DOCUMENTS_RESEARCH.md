# 安全書類（グリーンファイル）調査メモ — 実装前リファレンス

作成日: 2026-06-11
目的: DandoLink に安全書類作成機能を実装するための事前調査まとめ

---

## 1. 安全書類（グリーンファイル）とは

- 建設現場の安全を守る目的で、**着工前（現場入場前）に作成し元請に提出する書類群**の総称。正式には「労務安全書類」。緑色のファイルに綴じる慣習から「グリーンファイル」と呼ばれる。
- 施工体制台帳・作業員名簿などは建設業法により作成・保存が義務付けられている。
- 標準フォーマットは **全建統一様式**（一般社団法人 全国建設業協会が発行）。法的強制ではないが、業界の事実上の標準。元請が独自様式や電子システム（グリーンサイト、Buildee 等）を指定する場合もある。

### 最新版: 全建統一様式 改訂6版（令和6年10月 / 2024-10-01）

主な変更点:
- **押印欄の廃止**（電子化対応）→ PDF生成時にハンコ欄は不要
- 在留資格「特定活動」終了に伴う「外国人建設就労者」項目の削除
- ※改訂5版（2021-04）で「様式第5号-別紙 社会保険加入状況」は廃止され、作業員名簿に統合済み

### 保存期間

| 書類 | 保存期間 |
|---|---|
| 施工体制台帳・施工体系図・作業員名簿・安全衛生関係 | 工事完了後 **5年** |
| 完成図書・打ち合わせ記録 | 引き渡し後 **10年** |

## 3. 主要書類の記載項目詳細

### 3.1 作業員名簿（様式第5号）— 詳細

**ヘッダー部**
- 事業所名（工事名）、元請所長名
- 作成日・提出日
- 一次会社名・代表者名、（二次以降の場合）何次請＋会社名・代表者名
- CCUS 事業者ID（任意）

**作業員1人あたりの項目**
- 氏名・ふりがな、CCUS技能者ID（任意）
- 職種（例: とび、足場、オペレーター）
- 属性記号（複数可）: 現=現場代理人 / 主=作業主任者 / 女 / 未=18歳未満 / 基=基幹技能者 / 技=主任技術者 / 職=職長 / 安=安全衛生責任者 / 能 / 再 / 習
- 雇入年月日、経験年数（※会社所属年数ではなく職種の通算経験）
- 生年月日、年齢
- 現住所、TEL、家族連絡先（緊急連絡先）、家族TEL
- 最新の健康診断日（雇入時＋年1回義務 / 労安法66条）
- 血圧（最高-最低）、血液型
- 特殊健康診断日・種類（じん肺、有機溶剤、石綿等。非該当なら空欄）
- 教育・資格:
  - 雇入・職長・特別教育（足場の組立て等特別教育 など）
  - 技能講習（足場の組立て等作業主任者、玉掛け、小型移動式クレーン など）
  - 免許（国家資格）
- 社会保険:
  - 健康保険: 健康保険組合 / 協会けんぽ / 建設国保 / 国民健康保険 / 適用除外
  - 年金保険: 厚生年金 / 国民年金 / 受給者
  - 雇用保険: 雇用保険（番号下4桁） / 日雇保険 / 適用除外
- 建退共・中退共の加入有無
- 入場年月日・受入教育実施年月日（通常は元請が後から記入 → 空欄で出す）

**⚠️ プライバシー上の禁止事項（実装で必ず守る）**
- **健康保険の記号・番号は記載禁止**（2020-10 健康保険法改正、告知要求制限）→ 入力欄を作らない
- **基礎年金番号も記載禁止**（国民年金法108条の4）→ 入力欄を作らない
- 雇用保険のみ「下4桁」を記載

### 3.2 再下請負通知書（様式第1号-甲）

- 報告下請負業者: 会社名、住所、代表者名、建設業許可番号（許可業種・大臣/知事・般/特・番号・許可日）
- 注文者（直近上位）情報、元請名、工事名・工事内容・工期
- 再下請負業者: 会社名、住所、代表者、許可番号、工事内容、工期、**契約日**、健康保険等の加入状況
- 配置技術者: 主任技術者名（専任/非専任）、安全衛生責任者、安全衛生推進者、雇用管理責任者
- 注意点: 下請契約締結後速やかに提出。金額記載が求められる様式では**税込**。施工体制台帳・体系図と業者名・工事内容の整合をとる。主任技術者の専任要件（請負額による）に注意。

### 3.3 持込機械等使用届（参考第5号）

- 機械名・型式・製造番号・メーカー、点検日・点検結果、使用者氏名
- 持込時の点検表・定期自主検査記録の添付が前提。「電動工具一式」ではなく種類ごとに記載
- 受理されると持込機械届済証（ステッカー）が交付される

### 3.4 移動式クレーン・車両系建設機械等使用届（第9号）

- 機械種別、型式、性能（吊上荷重等）、検査証番号・有効期限
- オペレーター氏名・資格（免許/技能講習/特別教育の別と番号）
- 自主検査・点検記録

### 3.5 工事・通勤用車両届（参考第8号）

- 車番、車種、所有会社、運転者名、免許種別・番号、任意保険の加入状況（保険会社・期間・対人対物金額）

### 3.6 新規入場時等教育実施報告書（第7号）

- 実施日、場所、教育内容（現場の安全ルール、危険箇所等）、受講者名簿、実施者

### 3.7 工事安全衛生計画書（第6号）

- 工事概要、工期、安全衛生方針・目標、月間工程と主な作業、作業ごとの危険要因と対策、使用機械、有資格者配置、緊急時連絡体制

## 4. DandoLink への実装に向けた所見

### 既存データとのマッピング（活用できる資産が多い）

| 安全書類の要素 | DandoLink の既存データ |
|---|---|
| 工事名・工期・現場住所 | 案件マスター |
| 元請情報 | 顧客管理（元請） |
| 自社情報 | 設定（会社情報） |
| 作業員情報 | ユーザー管理（※安全書類用の項目が大幅に不足 → 作業員マスター拡張が必要） |
| 車両情報 | 車両マスター（工事・通勤用車両届にほぼ直結） |
| PDF生成 | @react-pdf/renderer / jsPDF（見積書・請求書で実績あり） |

### 設計上のポイント

1. **マスター駆動**: 「作業員マスター」「機械マスター」を一度整備すれば、現場ごとの書類は「案件 × 作業員選択」でほぼ自動生成できる。これが工数削減の核。
2. **個人情報の扱い**: 作業員名簿は生年月日・住所・血液型・保険情報などセンシティブ。保存時の暗号化やアクセス制御（RLS）、健康保険番号・基礎年金番号は**そもそも持たない**設計に。
3. **有効期限アラート**: 健康診断（1年）、特殊健診（半年）、資格・免許、クレーン検査証、任意保険 — 期限管理は電子化の主要価値。
4. **押印欄は不要**（改訂6版で廃止）。PDF出力は A4 横/縦の様式に準拠。
5. **様式の著作権**: 全建統一様式そのもののExcelは全建が販売しているが、「準拠した様式」を自作するのは一般的な実務（各SaaSも同様）。レイアウトは独自に作成し「全建統一様式準拠」とする。
6. **元請による差異**: 元請ごとに独自様式・指定システム（グリーンサイト等）がある。まずは全建統一様式準拠のPDF出力を作り、自社→元請への提出物としては十分なケースが多い。
7. **優先順位の提案**: ①作業員名簿 → ②工事・通勤用車両届（車両マスター活用）→ ③持込機械等使用届 → ④新規入場時等教育実施報告書 → ⑤再下請負通知書 → その他

### 未確定・ユーザーに確認したいこと

- 自社の立場: 一次下請が中心か？（再下請負通知書の要否に影響）
- 元請からの提出方法: 紙/PDFメール提出が中心か、グリーンサイト等の指定があるか
- 対象書類の範囲（まずどの書類から作るか）
- CCUS（建設キャリアアップシステム）の利用状況
