## 1. 図面データの形（土台。Claude Code が作成済み）

- 型: `types/roadPermitDrawing.ts`（`RoadPermitDrawing`・`DrawingEntity`・`DrawingLayer` など）
- 用紙と縮尺・座標変換: `lib/roadPermit/drawing/paper.ts`
- 幾何計算（距離・交点・面積・読取点の候補・選択の当たり判定）: `lib/roadPermit/drawing/geometry.ts`
- 既定値と正規化: `lib/roadPermit/drawing/defaults.ts`（`emptyDrawing`・`normalizeRoadPermitDrawing`・レイヤの既定 7 枚）
- 入力チェック: `lib/validations/roadPermit.ts` の `roadPermitDrawingSchema`（PUT の `drawing`）

決まり:
- 図形は**実寸 mm・Y 上向き**（JWW・DXF と同じ）。画面と PDF は縮尺で表示するだけ。
- 用紙は A4 横／A3 横（縦も可）。`origin` = 用紙の左下隅に来る図面座標。用紙上の位置（mm）= `(p − origin) / scale`。
- 文字と寸法の文字の大きさは**用紙上の高さ（mm）**で持つ（縮尺を変えても印刷の文字の大きさが変わらない＝JWW と同じ）。
- レイヤは 7 枚固定（0 道路・境界／1 建物・敷地／2 足場・養生／3 保安施設／4 車両／5 寸法・文字／6 下敷き）。表示／ロック／印刷の切り替え。
- 保存は Phase 1 と同じ「保存」ボタン（PUT `/api/road-permits/[id]` に `drawing` を含める）。自動保存はしない。

## 2. 作図画面（`components/RoadPermits/Drawing/`）

編集画面に「図面」タブを足す（基本／申請書／**図面**／添付・提出）。中身は画面イメージ（`docs/道路申請_作図画面イメージ.html`）に合わせる。

| 場所 | 中身 |
|---|---|
| 上: コントロールバー | いま選んでいる操作の設定（長さ・角度・幅・線種・書込レイヤ・文字の大きさなど）。数値入力の欄はここ |
| 左: 操作ボタン | 描く（線・連続線・矩形・円・2線・文字・寸法・引出線・ハッチ）／直す（範囲・消去・複写・移動・回転・反転・属性）／測る（距離・面積） |
| 中央: 用紙 | 用紙の枠（薄い灰色）と、その中の図面。方眼（表示切替）。react-konva の Stage |
| 右: レイヤ | 7 枚のレイヤ（表示チェック・ロック・印刷・書込レイヤの選択）。2b で記号パレット・占用面積をここに足す |
| 下: ステータスバー | 「◆始点を指示してください (L)自由点 (R)読取点」のような案内／用紙／縮尺／カーソル座標（mm）／表示倍率 |

操作（設計書 §6.2）: 左クリック=自由点／右クリック=読取点（端点・中点・交点・中心）／Shift=水平垂直／数値入力（長さ・角度）／Esc=中止／Ctrl+Z・Ctrl+Y／ホイール=カーソル中心のズーム／中ボタンまたは Space+ドラッグ=パン。

- 主に PC（マウス）で使う前提。タブレットは表示と軽い修正まで（ピンチズーム・1 本指パンが動けばよい）。
- 読取点は候補に吸い付いたとき小さな印（□=端点・△=中点・×=交点・○=中心）を出す。
- 2線: 幅（mm）を入れて始点・終点を指示すると、中心線の両側に 2 本の線が引かれる（道路・歩道・側溝）。
- 寸法: 水平・垂直・斜め（2 点＋寸法線の位置）と連続寸法。寸法値は実寸 mm を自動（手で上書き可）。
- ハッチ: 閉じた連続線（または矩形）を選ぶと斜線で塗る。
- 範囲選択: 矩形で囲む（全部入ったものを選ぶ）。選んだ図形は色を変えて表示。消去・複写・移動・回転・反転・属性変更は「選んでから」操作する（JWW と同じ順）。
- 戻る／進む: 図形の変更 1 回ごと（50 回まで）。
- 設定: 用紙（A4/A3・横/縦）・縮尺（1/50・1/100・1/200・1/250・1/300）・原点（「用紙の左下をここに」）。縮尺を変えても図形の実寸は変わらない。

## 3. 図面の PDF（`components/pdf/roadPermit/DrawingPage.tsx`）

- 用紙サイズのページ（A4 横 842×595pt・A3 横 1191×842pt）。react-pdf の `Svg` で**線として**描く（画像にしない）。
- 中身: 用紙の枠（10mm 内側に細い枠線）・印刷するレイヤの図形・寸法（矢印と数値）・文字（NotoSerifJP）・ハッチ・**表題欄**（右下。図面名・場所・路線名・期間・縮尺・作成＝自社名。値は `values` から自動、`drawing.titleBlock` で上書き）・縮尺の棒（左下）・方位（北）。
- 申請書の PDF（`RoadPermitDocument`）の最後に、`includeDrawing` が true で図形が 1 つ以上あれば足す。「添付・提出」タブの「PDF を出す」に「図面も入れる」のチェック（図形があるとき既定オン）。
- 線の太さは 細 0.13mm／普通 0.25mm／太 0.5mm（pt に直す）。線種は 実線／破線／一点鎖線／点線。

## 4. 確かめ方

- Jest: 幾何計算（距離・交点・面積・読取点の候補・矩形選択）・座標変換（用紙↔実寸↔pt）・正規化。
- `npx tsc --noEmit`。既存のテストを壊さない。
- 画面: ログイン無しの見た目確認（scratchpad で esbuild＋tailwind＋Playwright。Phase 1 の支払明細書と同じやり方）か、`npm run dev` で本番 DB の既存の申請を開いて描く（**保存は押さない**）。
- PDF: `scripts/verify-road-permit-pdf.tsx` に `--drawing <json>` を足し、見本の図面（画面イメージの西条市の例: 道路 2線・建物・足場・寸法・文字）を描いた JSON から PDF を作って画像で確かめる。
